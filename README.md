# QR Code Generator

A simple Python project that generates a QR code from any text or URL and saves it as an image.

## Features

* Generate QR codes from text or URLs
* Save QR codes as PNG images
* Simple and beginner-friendly

## Technologies Used

* Python
* QRCode Library
* Pillow

## Concepts Learned

* User input
* Python libraries
* Image generation
* File handling
* Saving files
